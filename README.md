# ⚡ Simulación de Filtro Butterworth en MATLAB con Integración Hardware

## 📌 Descripción

Simulación y validación de un **filtro eléctrico Butterworth** utilizando diferentes entornos de MATLAB, integrando modelado teórico, simulación y prueba con hardware mediante microcontrolador.

---

## 🎯 Objetivos

* Analizar el comportamiento de un filtro Butterworth
* Comparar resultados en distintos entornos de simulación
* Validar la respuesta del sistema mediante adquisición de datos reales

---

## 🧠 Metodología

Se implementó el sistema mediante tres enfoques:

* **Simulink**: modelado del sistema dinámico
* **Simscape**: representación física del circuito eléctrico
* **MATLAB (código)**: análisis numérico y respuesta en frecuencia

Adicionalmente, se realizó conexión con hardware usando Arduino Uno para adquisición/señalización de datos.

---

## ⚙️ Sistema

* Tipo: Filtro pasa-bajas Butterworth
* Implementación: Analógica y simulada
* Análisis: Respuesta temporal y en frecuencia

---

## 🔌 Integración Hardware

* Interfaz MATLAB–Arduino
* Lectura/generación de señales
* Validación de comportamiento frente a simulación

---

## 📊 Resultados

* Comparación entre modelos (Simulink vs Simscape vs MATLAB)
* Evaluación de estabilidad y respuesta del filtro
* Coherencia entre simulación y medición experimental
